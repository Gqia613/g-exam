# G検定 模擬試験 一問一答

模擬試験PDF（問題・解答）を一問一答形式で解けるようにした静的サイトです。

- 全191問を10問ずつのセットで出題（PDFの並び順どおり）
- 選択して「回答する」で正誤・正解・解説（全文）を表示
- 数式・表・図を含む問題は、PDFから切り出した原文画像を表示（全問で「原文画像／テキスト」切替可）
- 回答記録はブラウザ（localStorage）にのみ保存

## 構成
- `index.html` / `style.css` / `app.js` … アプリ本体
- `data.js` … 問題・解答データ（PDFから抽出）
- `images/q`, `images/a` … 問題・解答の原文切り出し画像

## GitHub Pages
リポジトリの Settings → Pages で `main` ブランチの `/ (root)` を指定すれば配信できます。
